# Установка и настройка OpenClaw на MacBook Pro (Intel)

Простая пошаговая инструкция: как поставить [OpenClaw](https://openclaw.ai/) на
**второй** ноутбук MacBook Pro (процессор **Intel**), войти по подписке **Claude
Pro** и настроить личного и рабочего ассистента — с Telegram-ботом, памятью,
автоматизацией и безопасными настройками по умолчанию.

> Инструкция рассчитана на **отдельную (standalone)** установку — свой Gateway
> прямо на этом ноутбуке, без подключения к другому компьютеру.

> ℹ️ Команды сверены с официальной документацией на момент написания. OpenClaw
> быстро развивается — если что-то из написанного не совпадает с тем, что вы
> видите, сверьтесь с `openclaw --help` или `openclaw <команда> --help`.

## Что такое OpenClaw

OpenClaw — это self-hosted (запускаемый у себя) персональный AI-ассистент. Он
поднимает локальную фоновую службу — **Gateway** (порт `18789`), — через которую
агент работает и подключается к каналам (Telegram, CLI и т. д.).

На Intel-Mac всё работает штатно. Единственное отличие от Apple Silicon: Homebrew
ставится в `/usr/local` (а не в `/opt/homebrew`) — это пригодится в разделе
[про проблемы](#частые-проблемы-на-intel-mac).

## Что OpenClaw может делать для вас

Прежде чем ставить, полезно понять, что реально можно поручить ассистенту. Вот
типичные сценарии — личные и рабочие:

- **Утренняя сводка** — каждое утро в Telegram приходит дайджест: задачи на день,
  важные письма, ближайшие встречи (через `cron`, см. ниже).
- **Разбор почты и календаря** — попросить «что важного пришло за ночь» или
  «есть ли конфликты в расписании на этой неделе» (нужен MCP-коннектор к
  почте/календарю).
- **Черновики и переписка** — «набросай ответ клиенту о переносе созвона»,
  «сократи это письмо до трёх предложений».
- **Подготовка документов и заметок** — пересказ длинной статьи или PDF,
  структурирование заметок встречи, черновик документа по тезисам.
- **Рутинная автоматизация** — регулярные напоминания, еженедельные отчёты,
  проверка статуса задач в трекере (через MCP-интеграции).
- **Быстрые вопросы в течение дня** — прямо из Telegram, без необходимости
  открывать ноутбук: «переведи этот текст», «посчитай», «объясни термин».
- **Личный помощник** — планирование дел, напоминания, помощь с бытовыми
  задачами (маршруты, бронирования, списки).

Важно реалистичное ожидание: агент полезен там, где вы даёте ему чёткий контекст
и доступ к нужным инструментам (см. разделы [MCP](#инструменты-mcp-и-автоматизация-cron)
и [Память](#память-ассистента)). Из коробки, без интеграций, это просто чат с
Claude — ценность растёт по мере настройки.

## Что понадобится

- **macOS** на MacBook Pro (Intel) и доступ в интернет.
- Приложение **Terminal** (Терминал). Команды ниже написаны для **zsh** —
  это шелл по умолчанию в современном macOS; если у вас bash, замените
  `~/.zshrc` на `~/.bash_profile` в командах, где это встречается.
- Активная подписка **Claude Pro** — по ней будем авторизовывать агента.
- **Пароль администратора** этого Mac — понадобится для установки Homebrew.
- **Xcode Command Line Tools** — часто требуются для сборки нативных зависимостей
  (например, библиотеки `sharp`, см. раздел про проблемы). Если их ещё нет,
  macOS сама предложит установить при первой попытке использовать `git` или
  Homebrew; либо поставьте заранее: `xcode-select --install`.
- **Свободное место на диске** — не критично, но 2–3 ГБ под Node, зависимости и
  кеши будут не лишними.
- **Node.js вручную ставить не нужно** — установщик поставит нужную версию сам
  (OpenClaw требует Node 24; скрипт при необходимости подтянет Homebrew и Node).

## Быстрый старт за 15 минут

Если хочется просто увидеть результат, а не читать весь гайд — вот минимальный
путь. Остальные разделы документа — это углубление и донастройка под себя,
к ним можно вернуться позже.

1. **Установить** — вставить команду в Terminal ([Шаг 1](#шаг-1-установка-одной-командой)).
2. **Пройти онбординг** — выбрать Anthropic, войти по подписке Claude Pro
   ([Шаг 2](#шаг-2-онбординг-мастер-настройки)).
3. **Включить базовую защиту** — одна команда, чтобы агент не выполнял команды
   без вашего согласия ([Шаг 3](#шаг-3-включить-базовую-защиту)).
4. **Поставить демон и проверить** — Gateway работает в фоне, `openclaw doctor`
   без ошибок ([Шаг 4](#шаг-4-gateway-как-фоновая-служба-демон) и
   [Шаг 5](#шаг-5-проверка)).
5. **Написать первое сообщение** — через браузер или Telegram
   ([Шаг 6](#шаг-6-подключение-telegram-бота-личный-ассистент) и
   [Шаг 7](#шаг-7-первый-разговор-с-ассистентом)).

Дальше — по желанию: память, автоматизация через cron, подключение рабочих
инструментов через MCP.

## Шаг 1. Установка одной командой

Откройте Terminal и выполните:

```bash
curl -fsSL https://openclaw.ai/install.sh | bash
```

Скрипт сам определит систему, при необходимости установит Homebrew и Node 24,
поставит OpenClaw и запустит мастер онбординга.

## Шаг 2. Онбординг (мастер настройки)

Если мастер не запустился автоматически — запустите его вручную:

```bash
openclaw onboard
```

Пройдите шаги мастера:

1. **Режим настройки** — выберите **QuickStart** (быстрый старт с разумными
   значениями по умолчанию: Gateway на порту `18789`, token-auth, только локальный
   доступ). Advanced нужен только для тонкой ручной настройки.
2. **Провайдер модели** — выберите **Anthropic**.
3. **Способ входа** — так как у вас подписка **Claude Pro**, выберите вход
   **через логин Claude CLI** (локальная сессия) или **setup-token**:
   - если на этом Mac уже установлен Claude Code и вы вошли под своей подпиской —
     OpenClaw просто переиспользует этот логин, никаких дополнительных действий;
   - если нет — пройдите **setup-token flow**: мастер покажет ссылку (или код),
     вы откроете её в браузере, войдёте под своим аккаунтом Claude Pro и
     подтвердите доступ — мастер в Terminal сам обнаружит успешный вход и
     продолжит настройку.

> ⚠️ **Не выбирайте вариант «Anthropic API key».** API-ключ — это отдельная
> оплата по факту использования (pay-as-you-go) и подписку Claude Pro он **не**
> задействует. Для работы по подписке нужен именно вход через Claude CLI /
> setup-token.
>
> Учтите также, что запросы OpenClaw расходуют лимиты вашей подписки Claude Pro
> (подробнее — в разделе [«Лимиты подписки Claude Pro»](#лимиты-подписки-claude-pro)).

**Если вход по подписке не проходит.** Anthropic периодически меняет условия
использования подписки в сторонних инструментах (см.
[раздел про лимиты](#лимиты-подписки-claude-pro)). Если setup-token flow
недоступен или блокируется:

1. Проверьте статус на странице [провайдера Anthropic](https://docs.openclaw.ai/providers/anthropic) —
   там актуальные условия.
2. Как запасной вариант можно пройти онбординг с **Anthropic API key** —
   это временно снимет блокировку, но учтите: биллинг пойдёт отдельно
   (pay-as-you-go), а не из вашей подписки Pro. Ключ можно получить в
   [консоли Anthropic](https://console.anthropic.com/).
3. Когда вход по подписке снова заработает — перезапустите
   `openclaw onboard` и выберите его вместо API-ключа.

## Шаг 3. Включить базовую защиту

> ⚠️ **Сделайте это до подключения Telegram.** По умолчанию OpenClaw может
> выполнить **любую** shell-команду на вашем Mac без ограничений и без спроса.
> Если сначала подключить бота в Telegram (Шаг 6), а базовую защиту включить
> потом — какое-то время агент, доступный из чата, будет работать вообще без
> подтверждений.

Включите режим, при котором агент спрашивает подтверждение перед незнакомыми
командами:

```bash
openclaw config set tools.exec.mode ask
openclaw gateway restart
```

Этого достаточно для безопасного старта. Подробный разбор всех режимов,
пресетов и способов подтверждения — в разделе
[«Безопасность: подробный разбор режимов»](#безопасность-подробный-разбор-режимов)
дальше по документу; туда стоит вернуться перед тем, как давать агенту доступ к
важным рабочим системам.

## Шаг 4. Gateway как фоновая служба (демон)

Чтобы Gateway работал в фоне и не выключался после закрытия Terminal, установите
его как службу:

```bash
openclaw gateway install
```

> 💡 Если вы ещё не проходили Шаг 2 — демон можно поставить сразу вместе с
> онбордингом одной командой `openclaw onboard --install-daemon`, чтобы не
> запускать мастер настройки дважды. Если онбординг уже пройден (как в этом
> гайде) — используйте отдельную команду выше.

На macOS будет установлен **LaunchAgent** — Gateway поднимется автоматически и
переживёт закрытие терминала и перезагрузку.

## Шаг 5. Проверка

Убедитесь, что всё поднялось:

```bash
openclaw --version          # версия CLI — значит, установка прошла
openclaw doctor             # проверка конфигурации, без ошибок
openclaw gateway status     # статус Gateway — должно быть running
openclaw models status      # авторизация провайдера — профиль активен
```

Если `openclaw doctor` не показывает ошибок, а `gateway status` = `running` —
базовая установка готова. Если что-то не сходится — сразу загляните в раздел
[«Первая помощь при сбоях»](#первая-помощь-при-сбоях).

## Шаг 6. Подключение Telegram-бота (личный ассистент)

Так вы сможете общаться с ассистентом прямо из Telegram, а не только с ноутбука.

### 6.1. Создать бота

В Telegram напишите официальному боту [@BotFather](https://t.me/BotFather)
(проверьте, что имя точно `@BotFather`):

1. Отправьте команду `/newbot`.
2. Задайте отображаемое имя и username бота.
3. Скопируйте и сохраните **токен**, который выдаст BotFather.

> 🔒 Токен — как пароль: кто угодно с ним может управлять вашим ботом. Держите его
> в секрете. Если утёк — сделайте `/revoke` у BotFather и получите новый.

### 6.2. Добавить токен в OpenClaw

Проще всего — через **Control UI**: откройте `http://localhost:18789/` →
раздел **Channels** → **Telegram** → вставьте токен и укажите свой Telegram ID
в списке разрешённых. Панель сама сохранит и подставит нужную структуру конфига.

Если предпочитаете терминал — тот же результат даёт ручная правка файла
конфига. Откройте его в редакторе:

```bash
open -e ~/.openclaw/openclaw.json
```

и добавьте (или дополните) секцию `channels.telegram`:

```json
{
  "channels": {
    "telegram": {
      "enabled": true,
      "botToken": "ВАШ_ТОКЕН",
      "dmPolicy": "pairing",
      "allowFrom": ["ВАШ_TELEGRAM_ID"]
    }
  }
}
```

- `allowFrom` — ваш **числовой Telegram ID**, чтобы с ботом не мог говорить кто
  попало. Узнать ID можно так: запустите `openclaw logs --follow`, напишите боту
  любое сообщение и посмотрите ID в логе.
- Альтернатива токену в конфиге — переменная окружения
  `TELEGRAM_BOT_TOKEN=ваш_токен` (работает для аккаунта по умолчанию).
  Приоритет источников токена: `tokenFile` > `botToken` > переменная окружения.
- После ручной правки файла **обязательно** сохраните его и выполните команду
  из следующего шага — иначе изменения не применятся.

### 6.3. Перезапустить Gateway

Чтобы канал подхватился, перезапустите Gateway:

```bash
openclaw gateway restart
```

### 6.4. Спаривание (pairing)

Напишите своему боту в Telegram любое сообщение, затем на Mac подтвердите доступ:

```bash
openclaw pairing list telegram            # показать ожидающие коды
openclaw pairing approve telegram <КОД>   # подтвердить свой код
```

Коды действуют **1 час**. После подтверждения бот начнёт отвечать вам как
ассистент.

**Ожидаемый результат:** напишите боту «привет» — должен прийти осмысленный
ответ в течение нескольких секунд. Если бот молчит — проверьте
`openclaw channels status --probe` и раздел
[«Первая помощь при сбоях»](#первая-помощь-при-сбоях).

## Шаг 7. Первый разговор с ассистентом

Есть два простых способа начать пользоваться:

- **Через Telegram** — после спаривания (Шаг 6) просто напишите своему боту любое
  сообщение, и он ответит.
- **Через браузер (Control UI)** — откройте панель управления Gateway по адресу
  `http://localhost:18789/`, введите токен или пароль из онбординга и пишите прямо
  в чат на странице. Там же видно агентов, инструменты, скиллы и логи.

Примеры первых промптов, чтобы попробовать (см. также
[«Что OpenClaw может делать для вас»](#что-openclaw-может-делать-для-вас)):

```text
Составь список дел на сегодня из этих задач: ...
Кратко перескажи статью по ссылке: https://example.com/article
Напиши черновик письма коллеге о переносе встречи на пятницу
```

**Ожидаемый результат:** ассистент отвечает по существу и помнит контекст в
рамках одного разговора. Чтобы он запоминал что-то *между* разговорами —
смотрите раздел [«Память ассистента»](#память-ассистента).

> 🔒 Не открывайте Control UI (порт `18789`) в интернет напрямую. Для доступа с
> других устройств используйте Tailscale или SSH-туннель — так панель остаётся под
> защитой токена/пароля.

## Управление и настройка агента

- **Главный конфиг** — `~/.openclaw/openclaw.json`. Читать и менять значения
  удобнее командами, а не руками:

  ```bash
  openclaw config get <ключ>
  openclaw config set <ключ> <значение>
  ```

- **Применить изменения конфига** — перезапустить Gateway:

  ```bash
  openclaw gateway restart
  # полный цикл при необходимости:
  openclaw gateway stop && openclaw gateway start
  ```

- **Диагностика и здоровье:**

  ```bash
  openclaw doctor --fix              # проверка + авто-починка типовых проблем
  openclaw status --deep             # живые пробы всех подключённых каналов
  openclaw logs --follow --local-time  # лог в реальном времени, время в вашей зоне
  ```

- **Настройки самого агента** (модель, поведение, доступные скиллы) живут в
  секциях `agents.defaults` и `agents.list[]` в `openclaw.json`. Сменить
  провайдера или перелогиниться — снова `openclaw onboard`; проверить
  авторизацию — `openclaw models status`.

- **Выключить или приостановить ассистента.** Если хотите временно отключить
  доступ (уезжаете, не хотите тратить лимиты, или просто хотите тишины):

  ```bash
  openclaw gateway stop    # остановить Gateway — бот и Control UI перестанут отвечать
  openclaw gateway start   # снова включить, когда понадобится
  ```

  Демон при этом остаётся установленным — `stop`/`start` не требуют повторного
  онбординга.

## Безопасность: подробный разбор режимов

На [Шаге 3](#шаг-3-включить-базовую-защиту) вы уже включили режим `ask` —
для повседневного использования этого достаточно. Здесь — более полное
объяснение, на случай если хотите настроить точнее (например, перед тем как
подключать агента к важным рабочим системам).

За выполнение команд отвечает политика `tools.exec.mode` с режимами:

- `deny` — запретить выполнение команд полностью;
- `allowlist` — выполнять без вопросов только команды из «белого списка»;
- `ask` — как allowlist, но при незнакомой команде спрашивать подтверждение
  *(рекомендуется для новичка и уже включено на Шаге 3)*;
- `auto` — авто-проверка перед запросом к человеку;
- `full` — выполнять всё без подтверждений (небезопасно).

Быстрые пресеты:

```bash
openclaw exec-policy preset cautious   # allowlist + спрашивать при промахе
openclaw exec-policy preset deny-all   # запретить все команды
openclaw exec-policy preset yolo       # без подтверждений (не рекомендуется)
```

Когда агент просит подтверждение, ответить можно прямо в чате: реакциями
✅ (разрешить один раз), ♾️ (разрешить всегда), ❌ (запретить) или командой
`/approve`. Список разрешённых команд хранится в файле
`~/.openclaw/exec-approvals.json`.

## Приватность и рабочие данные

Если планируете использовать ассистента и для рабочих задач, важно понимать,
куда уходят данные и что видит агент.

- **Что уходит в облако.** Ваши сообщения и запросы к модели обрабатываются
  через API Anthropic (по вашей подписке Claude Pro) — так же, как при обычном
  использовании Claude или Claude Code. Это происходит при каждом ответе агента.
- **Что остаётся локально.** Конфигурация, ключи, история диалогов и файлы
  памяти хранятся на вашем Mac в `~/.openclaw/` (Gateway работает локально, а
  не в чужом облаке). Подробнее — в разделе
  [«Память ассистента»](#память-ассистента).
- **Подключая рабочие инструменты через MCP** (почта, календарь, таск-трекер,
  файловое хранилище — см. [раздел MCP](#инструменты-mcp-и-автоматизация-cron)),
  вы даёте агенту доступ читать (а иногда и изменять) эти данные. Прежде чем
  подключать рабочий аккаунт, проверьте:
  - разрешает ли политика вашей компании использовать сторонние AI-инструменты
    с рабочей почтой/документами;
  - не нарушает ли это NDA или условия обработки данных клиентов;
  - что конкретно умеет MCP-сервер (только чтение или ещё и запись/отправка).

> ⚠️ **Рекомендация.** Личная подписка Claude Pro и личный Mac — это ваша
> собственная среда, но рабочие данные, которые вы через неё пропускаете,
> остаются рабочими данными. Если сомневаетесь — уточните у ИТ/безопасности на
> работе, прежде чем подключать корпоративную почту, календарь или внутренние
> системы. Для рабочих задач можно завести **отдельного агента** в секции
> `agents.list[]` с ограниченным набором инструментов и MCP-подключений — так
> личное и рабочее не будут смешиваться в одной памяти.

## Добавление и использование скиллов

**Скилл** — это папка с файлом `SKILL.md` (YAML-фронтматтер + markdown-инструкция),
которая учит агента новой способности и объясняет, когда её применять.

```bash
openclaw skills                          # список установленных скиллов (= skills list)
openclaw skills install <имя>            # установить скилл из ClawHub
openclaw skills install <имя> --global   # в общий ~/.openclaw/skills для всех агентов
openclaw skills check                    # проверить корректность скиллов (после апгрейда)
```

- По умолчанию скилл ставится в папку `skills/` текущего воркспейса; флаг
  `--global` кладёт его в общий каталог `~/.openclaw/skills`, видимый всем
  локальным агентам.
- **Видимость скиллов** для конкретного агента настраивается в конфиге через
  `agents.defaults.skills` и `agents.list[].skills`.
- **Skill Workshop** — очередь предложений: когда агент замечает переиспользуемую
  работу, он предлагает новый скилл, а вы подтверждаете его перед добавлением.

> 💡 Совет: начинайте с **минимального** набора скиллов под основные задачи и
> добавляйте новые по мере необходимости. Слишком много скиллов = лишний шум, и
> агент начинает применять их не к месту.

## Память ассистента

Чтобы ассистент помнил ваши предпочтения и контекст между разговорами, OpenClaw
хранит память как **обычные Markdown-файлы** в воркспейсе агента
`~/.openclaw/workspace`. Важный принцип: модель помнит только то, что записано на
диск, — скрытого состояния нет.

Основные файлы:

- **`MEMORY.md`** — долгосрочная память: факты, предпочтения и решения, которые
  агент должен помнить всегда. Загружается автоматически в начале каждой сессии.
- **`memory/YYYY-MM-DD.md`** — ежедневные заметки с деталями и итогами сессий.
  Заметки за сегодня и вчера подгружаются автоматически.
- **`DREAMS.md`** (опционально) — дневник «снов»: сводки фоновой консолидации.
  Периодический процесс **dreaming** переносит важное из ежедневных заметок в
  `MEMORY.md`.

Как пользоваться:

- Просто попросите в чате: **«Запомни, что я предпочитаю…»** — агент сам допишет
  нужный файл.
- Можно отредактировать `MEMORY.md` вручную и заранее «засеять» стартовые факты.
- Импортировать память из Claude Code можно через Control UI → **Settings**.
- Поиск и статус памяти из терминала:

  ```bash
  openclaw memory search "что я говорил про проект X"
  openclaw memory status
  ```

> 💡 Память лежит внутри `~/.openclaw/`, поэтому резервная копия из раздела ниже
> уже включает и её.

## Инструменты (MCP) и автоматизация (cron)

Две вещи, которые превращают ассистента из «чат-бота» в полезного помощника.

### Внешние инструменты через MCP

**MCP** (Model Context Protocol) — открытый стандарт, через который агент
подключается к внешним инструментам: почта, календарь, файлы, базы данных, GitHub
и сотни других (500+ готовых серверов). Управлять подключениями можно командой
`openclaw mcp` или во вкладке **MCP Servers** в Control UI; авторизация — через
OAuth или API-ключ сервиса.

```bash
openclaw mcp            # список и управление MCP-серверами
```

> См. также [«Приватность и рабочие данные»](#приватность-и-рабочие-данные) —
> прежде чем подключать рабочие аккаунты.

### Расписания через cron

**Cron** — встроенный планировщик Gateway: он будит агента по расписанию и может
доставлять результат прямо в чат (например, в Telegram).

```bash
# каждый день в 7:00 — утренняя сводка с доставкой в Telegram
openclaw cron create "0 7 * * *" "Сделай утреннюю сводку" \
  --name "Morning brief" --announce --channel telegram --to "ВАШ_TELEGRAM_ID"

openclaw cron list             # список заданий
openclaw cron remove <job-id>  # удалить задание
```

## Обновление, удаление и резервная копия

**Обновить** до последней версии — одной командой (авто-определит тип установки,
обновит, мигрирует конфиг и перезапустит Gateway):

```bash
openclaw update
openclaw update --channel beta   # если хотите свежие бета-сборки вместо stable
```

Как альтернатива — повторно запустить установщик с сайта: он обновит установку
на месте.

**Резервная копия.** Всё важное лежит в папке `~/.openclaw/` — конфиг, ключи,
сессии, задания cron, память и скиллы. Достаточно скопировать эту папку:

```bash
cp -r ~/.openclaw ~/openclaw-backup
```

**Удаление:**

```bash
brew uninstall openclaw   # если ставили через Homebrew
# при желании удалить и данные:
rm -rf ~/.openclaw
```

## Лимиты подписки Claude Pro

OpenClaw работает на вашей подписке **Claude Pro** и тратит её лимиты так же, как
обычный Claude Code. Что важно понимать новичку:

- **Фоновые задачи (cron) и тяжёлые прогоны** расходуют лимит быстрее всего — не
  гоняйте тяжёлую автоматизацию 24/7 на Pro.
- **При исчерпании лимита** ответы приостанавливаются до сброса окна использования;
  иногда агент «молча деградирует» — отвечает хуже или обрывается. Причину видно в
  `openclaw logs --follow`.
- **Как экономить:** для рутинных задач выбирайте модель попроще, а тяжёлые запросы
  запускайте осознанно. Если лимитов не хватает — рассмотрите план **Max** или
  отдельную оплату (Agent SDK credits / API-ключ).

**Выбор модели под задачу.** Модель агента настраивается в `agents.defaults`
или `agents.list[]` в `openclaw.json` (см. раздел
[«Управление и настройка агента»](#управление-и-настройка-агента)). Практическое
правило: для рутины (короткие ответы, простые команды, черновики) — модель
попроще и быстрее; для сложных задач (анализ, код, многошаговые рассуждения) —
более сильную модель. Это прямо влияет на то, как быстро расходуется лимит
подписки.

> ⚠️ Политика Anthropic по использованию подписки в сторонних инструментах в
> 2026 году менялась несколько раз (апрельское ограничение → анонс «Agent SDK
> credits» → пауза изменения от 15 июня, которое так и не вступило в силу). На
> момент написания подписка работает как раньше, но тема подвижная — при сомнениях
> сверяйтесь с актуальными условиями Anthropic и страницей
> [провайдера Anthropic](https://docs.openclaw.ai/providers/anthropic).

## Первая помощь при сбоях

Универсальный алгоритм при любой проблеме — сначала эти две команды:

```bash
openclaw doctor --fix           # найдёт и попробует починить типовые проблемы
openclaw logs --follow --local-time   # покажет, что происходит, в реальном времени
```

Типовые ситуации новичка:

- **Gateway не стартует.** Проверьте `openclaw gateway status`; если статус не
  `running`, посмотрите `openclaw logs --follow` в момент попытки запуска —
  обычно там видна причина (например, конфликт порта, см. ниже).
- **Порт `18789` занят другим процессом.** Узнать, кто занял порт:
  `lsof -i :18789`. Либо остановите конфликтующий процесс, либо смените порт
  Gateway в конфиге (`openclaw config set gateway.port <другой_порт>`) и
  перезапустите.
- **Демон не поднялся после установки.** Убедитесь, что команда
  `openclaw gateway install` отработала без ошибок; проверьте статус
  LaunchAgent: `launchctl list | grep openclaw`. Переустановить —
  `openclaw gateway install` ещё раз (безопасно выполнять повторно).
- **Ошибка входа/логина по подписке.** Смотрите раздел
  [«Если вход по подписке не проходит»](#шаг-2-онбординг-мастер-настройки)
  в Шаге 2 — там разобран fallback через API-ключ.
- **Telegram-бот не отвечает.** Проверьте `openclaw channels status --probe` и
  убедитесь, что спаривание подтверждено (`openclaw pairing list telegram` не
  должен показывать ваш код как ожидающий).

Если ничего из этого не помогло — `openclaw doctor` обычно указывает точную
причину в выводе; текст ошибки оттуда проще всего гуглить или сверять с
[официальной документацией](https://docs.openclaw.ai/).

## Частые проблемы на Intel Mac

- **`command not found: openclaw` или `node`** — bin-каталог не в `PATH`. На Intel
  Homebrew лежит в `/usr/local`, подключите его и обновите `PATH`:

  ```bash
  eval "$(/usr/local/bin/brew shellenv)"
  echo 'eval "$(/usr/local/bin/brew shellenv)"' >> ~/.zshrc
  source ~/.zshrc
  ```

  > На Apple Silicon путь был бы `/opt/homebrew/bin/brew` — на вашем Intel-Mac это
  > именно `/usr/local`.

- **Ошибки библиотеки `sharp`** при установке — переустановите OpenClaw, заставив
  использовать готовые бинарники:

  ```bash
  SHARP_IGNORE_GLOBAL_LIBVIPS=1 npm install -g openclaw@latest
  ```

  Если не помогло — убедитесь, что установлены Xcode Command Line Tools
  (`xcode-select --install`), они нужны для сборки нативных зависимостей.

## Мини-глоссарий

- **Gateway** — локальная фоновая служба OpenClaw (порт `18789`), через которую
  агент работает и подключается к каналам.
- **Демон / LaunchAgent** — способ запускать Gateway в фоне на macOS так, чтобы
  он переживал закрытие терминала и перезагрузку.
- **MCP (Model Context Protocol)** — стандарт подключения агента к внешним
  инструментам (почта, календарь, файлы и т. д.).
- **Pairing (спаривание)** — процедура подтверждения, что именно вы управляете
  каналом (например, Telegram-ботом), а не кто-то посторонний.
- **Workspace (воркспейс)** — рабочая папка агента на диске
  (`~/.openclaw/workspace`), где хранятся память и другие рабочие файлы.
- **Allowlist** — «белый список» команд, которые агент может выполнять без
  дополнительного подтверждения.
- **Cron** — встроенный планировщик заданий по расписанию.
